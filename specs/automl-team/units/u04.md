## Plan

1. `automl_team/handoff.py` — frozen `Handoff` dataclass `{csv_path, report_markdown}`
   (DESIGN handoff contract) + `as_event_payload()`.
2. `automl_team/orchestrator.py`:
   - `Stage = (name, fn)` where `fn(ctx) -> Handoff | None`; `ctx` carries
     `run_dir`, `log` (EventLog), `upstream` (previous stage's Handoff), `data_csv`.
   - `run(data_csv, stages, runs_root="runs", echo=True)`:
     creates `runs/<YYYY-MM-DD_HH-MM-SS>/`, copies raw → `00_raw_data.csv`, emits `run_meta`
     with a **generic** stats fingerprint (shape, per-column dtype + missing fraction — no
     dataset-specific logic, NO-HARDCODE safe), then per stage: `stage_start` → fn → `handoff`
     (if a Handoff returned) → `stage_end(ok)`. Exception → `error` + `stage_end(failed)` +
     re-raise. `echo` mirrors every event through `console.render` to stdout.
   - Returns the run dir.
3. `tests/test_orchestrator.py` (no LLM): dummy 2-stage run on a tiny CSV →
   run-dir exists, `00_raw_data.csv` byte-equal to input, events.jsonl order is
   `run_meta, stage_start, handoff, stage_end, stage_start, stage_end`, fingerprint payload has
   shape + columns, second stage received first stage's Handoff, failing stage emits
   `error` + `stage_end(failed)` and re-raises.
