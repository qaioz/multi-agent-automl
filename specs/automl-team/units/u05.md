## Plan

1. **SDK verification (done first, against the installed package — `google-genai 2.8.0`):**
   manual function calling via `types.FunctionDeclaration(name, description, parameters=<JSON
   schema>)` → `types.Tool(function_declarations=[…])` → `types.GenerateContentConfig(tools=…,
   system_instruction=…)`; model reply parts carry `.text` / `.function_call`; tool results go
   back as `types.Part.from_function_response(name=…, response={…})` inside a `user`-role
   `types.Content`. No automatic-function-calling (we pass declarations, not callables — AFC
   never engages; logging stays ours).
2. `automl_team/llm.py` — `.env` loading (`python-dotenv`), `get_client()` (fails with a clear
   message if `GEMINI_API_KEY` missing), `get_model()` (`GEMINI_MODEL`, default
   `gemini-2.5-flash`).
3. `automl_team/agent.py` — the ONE generic loop (DESIGN §2):
   - `ToolDef(name, description, parameters, fn)`; harness-owned `finish(report_markdown)` is
     appended to every agent's declarations.
   - `run_agent(agent_name, system_prompt, task, tools, log, max_turns=…) -> Handoff-ish dict`:
     history → `generate_content` → text parts ⇒ `reasoning` events; function-call parts ⇒
     validate + execute, `tool_call`/`tool_result` events, result appended to history → repeat
     until `finish` or turn cap.
   - Malformed/unknown calls → error string returned *as the tool result* (agent self-corrects).
   - Turn cap hit → return best-effort with `finished=False` + `error` event.
   - `finish` validation hook (`finish_guard`) param — u11 uses it for the min-2-executions rule.
4. **Key check before nag:** `.env` already holds a `GEMINI_API_KEY` (found in u01) — try a
   1-token live call first; only nag if it fails.
5. Self-test (real API, flash): toy agent with one trivial tool (`reverse_string`) + task that
   forces tool use, then `finish`. Assert from `events.jsonl`: ≥1 `tool_call`+`tool_result`,
   ≥1 `reasoning`, loop ends via finish, every history arrow logged. Marked `@pytest.mark.llm`
   (skipped when no key) — suite stays green keyless.
