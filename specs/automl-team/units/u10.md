## Plan

1. `automl_team/tools/sandbox.py` — `Sandbox(run_dir, log, agent_name, timeout=120)`:
   - `execute_python_code(code)`: writes `code_iter_<n>.py` into the run dir (the generated
     code itself is an exhibit artifact), runs it with **`sys.executable`** (the project venv —
     generated code sees pandas/xgboost) and `cwd=run_dir`, captures stdout/stderr.
   - Timeout (`subprocess.TimeoutExpired`) → returncode −1 and the timeout explanation
     **appended to stderr** (+ any partial output) so the Trainer reacts to it like any error.
   - Logs the `execution` event with **verbatim full** stdout/stderr + iteration + returncode.
   - Returns to the agent: returncode + stdout + stderr, each stream **head+tail truncated at
     4 000 chars** (context cost control; the event keeps the verbatim copy — DESIGN's
     "verbatim capture" is about the log).
   - `executions` counter exposed (u11's min-2/max-6 guardrails read it).
   - `tooldef()` declaration.
2. `tests/test_sandbox.py` (no LLM): ok / crash / timeout return verbatim text + correct rc;
   `execution` events logged verbatim; `code_iter_n.py` files saved; cwd is the run dir;
   pandas imports inside the sandbox; truncation kicks in for huge prints (event still full).
