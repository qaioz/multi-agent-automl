   - `create_interaction(col_a, col_b, op, new_name)` — op ∈ add|subtract|multiply|divide
     (numeric-coerced; divide guards /0 → NaN); returns new-column stats.
   - `encode_categorical(column, method, order=None)` — onehot (new dummy cols, original
     dropped) | ordinal (order = JSON array string; unmapped values reported) | frequency.
   - `correlation_analysis(target=None)` — numeric-only; with target: per-feature corr sorted
     by |r|; without: top-15 strongest pairs.
   - `select_top_features(target, k=None, threshold=None)` — keeps target + numeric features by
     |corr| (top-k or ≥ threshold), drops the weak numeric rest; returns kept/dropped.
   - `count_items(column, sep, new_name)` — packed-list counter (NaN → 0).
   - `bucketize(column, rule, new_name)` — rule = JSON: `{"edges":[…], "labels":[…]?}` or
     `{"quantiles": n}`.
   - `tooldefs()` for all of the above + shared `inspect_metadata`/`drop_column`.
   All params agent-chosen; no dataset noun in source (NO-HARDCODE).
3. `tests/test_feature_tools.py` — every tool driven on the **real CSV** (it has the packed-list
   and categorical columns the verbs exist for) + error paths; u06 tests untouched and green.
