## Plan

1. `automl_team/tools/cleaner.py` — `CleanerTools(csv_path)` holding the stage's working
   dataframe; every verb is generic (column/strategy/params are **arguments**, never defaults;
   no dataset noun appears in the source):
   - `inspect_metadata()` → shape + per-column dtype/missing/nunique/sample values (JSON).
   - `get_column_stats(column)` → numeric describe or top value_counts + missing (JSON).
   - `impute_missing(column, strategy, value=None)` — `mean|median|mode|constant`; returns
     filled count. (`median` as an agent-chosen *argument* is fine — the u17 grep targets
     harness-chosen defaults; this fn errors without an explicit strategy.)
   - `drop_column(column)`.
   - `drop_rows(column, condition)` — condition string: `isna` or `<op> <literal>` with op in
     `> >= < <= == !=`; literal via `ast.literal_eval` (no eval); returns dropped count.
   - `normalize_categories(column, mapping=None)` — mapping = JSON-string dict (Gemini schemas
     don't do free-form objects well); without mapping: strip + casefold. Returns
     before/after nunique.
   - `save(path)`; `tooldefs()` → the `ToolDef` list with Gemini-schema declarations.
   - Unknown column / bad strategy / bad condition → `ValueError` with the valid options —
     the agent loop already feeds exceptions back as tool results (u05).
2. `tests/test_cleaner_tools.py` — every tool driven directly on the **real committed CSV**:
   metadata lists the dirt columns; stats on the Cyrillic-С column round-trips; impute mode on
   it fills its NaNs; constant-impute; drop_rows `> 1e8` removes the salary outliers; isna
   condition; normalize strip+casefold shrinks `Seniority level` nunique; mapping path; drop
   column; persistence via save; error paths (unknown column, bad strategy, bad condition,
   constant without value); declarations match the bound methods.
